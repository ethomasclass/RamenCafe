# Ramen Talk — concept handout

**Two pages. Front filled in while playing, back after the shop closes.**
Printable version: [`docs/print/handout.html`](print/handout.html) — open it and
hit print. It is laid out to come out as exactly two sheets of Letter.

This is the **short** worksheet, and the one to use if you are only using one.
It asks students to link named curriculum concepts to specific characters and
then *explain* the link, using AP task verbs. The longer
[student handout](STUDENT-HANDOUT.md) and the scaffolded
[guided notes](GUIDED-NOTES.md) are alternatives, not companions — pick one.

# After the shop closes

Answer in full sentences. **The verb tells you how much to write.**

| | |
|---|---|
| **Identify** | Name it. No explanation needed. |
| **Describe** | Give its characteristics. |
| **Explain** | Say *how* or *why* — cause and effect. |
| **Compare** | Give a similarity *and* a difference. |
